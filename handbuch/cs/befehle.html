Každý příkaz

Co dělá každý příkaz seznamu Události, každý příkaz kamery, každé makro a každé pole SET_ - s hodnotou, kterou očekává.

Příkazy se vkládají ze seznamu Události (dvojklik, přetažení nebo Insert) a mění v Editor událostí (dvojklik na řádek). Najeďte myší na příkaz v seznamu a přečtěte si text nápovědy, který k němu napsali designéři hry. Jak je skládat dohromady: Psaní skriptů.

Příkazy seznamu Události#

Každý příkaz má vlastní stránku s obrázky editoru a všech tří pohledů: Příkazy jeden po druhém.

PříkazCo děláPříklad
flushSmaže každý příkaz, který na tuto entitu ještě čeká - to, co dělá blok affect s FLUSH na svém začátku.flush ( )
if / elseSpustí blok, jen když porovnání platí (=, <, >, ! pro *nerovná se*). else musí následovat hned za if.if ( $get( FLOAT, "count")$, $>$, $2$ )
loopOpakuje svůj blok; číslo říká, jak často, -1 znamená navždy.loop ( 3 )
affectPošle příkazy svého bloku jedné entitě - postavě, lodi, dveřím - podle jejího názvu. FLUSH nahradí, co entita dělala, INSERT k tomu přidá. Skript sám na blok nečeká.affect ( "kyle", FLUSH )
runSpustí další skript na entitě, na které běží tento.run ( "taspir_tut/kyle_spawn" )
waitČeká tolik milisekund - nebo s názvem, dokud tato úloha neskončí.wait ( 2000 )
waitsignalČeká, dokud jiný skript nezavolá signal se stejným názvem. Na daný signál může čekat jen jeden skript.waitsignal ( "door_open" )
signalProbudí skript, který na tento název čeká.signal ( "door_open" )
soundPřehraje zvuk na kanálu entity - CHAN_VOICE pro dialog, aby se hýbala ústa.sound ( CHAN_VOICE, "sound/chars/kyle/..." )
movePosune entitu (dveře, plošinu, loď) na polohu - a je-li zadáno, na nové úhly - za tolik milisekund. Okno Animace je píše za vás (Dveře, které se otevírají).move ( < 0 0 128 >, < 0 0 0 >, 2000 )
rotateOtočí entitu na úhly (sklon, otočení, náklon) za tolik milisekund.rotate ( < 0 90 0 >, 1000 )
usePoužije entitu podle názvu, jako by ji stiskl hráč - otevře dveře, spustí trigger.use ( "door1" )
killZabije entitu s tímto názvem.kill ( "stormie1" )
removeOdebere entitu s tímto názvem ze hry.remove ( "stormie1" )
printZobrazí text uprostřed obrazovky.print ( "Hello" )
remKomentář - ve hře nic nedělá. Zakomentovat z něj udělá kterýkoli řádek.rem ( "camera starts here" )
declare / freeDeklaruje proměnnou (FLOAT, STRING, VECTOR; nejvýš 16 na mapu) - free název vrátí.declare ( FLOAT, "count" )
setMění hodnotu: pole entity (SET_NAVGOAL, SET_ANIM_BOTH, ... - viz úplný seznam níže) nebo deklarovanou proměnnou.set ( SET_WALKING, "true" )
cameraOvládá kameru animační sekvence; první hodnota volí, co dělá - viz další část.camera ( ENABLE )
taskDeklaruje pojmenovanou skupinu příkazů - ta ještě neběží.task ( "walk" )
doSpustí úlohu a hned pokračuje.do ( "walk" )
dowaitSpustí úlohu a počká, až skončí - u chůze: až postava dorazí.dowait ( "walk" )
playPřehraje soubor ROFF na entitě aktuálního bloku affect - zaznamenaný pohyb.play ( PLAY_ROFF, "taspir_tut/roffs/ravensClaw" )
Příkaz označený v textu nápovědy * (například SET_NAVGOAL) dokončí svou úlohu, až když je akce hotová - díky tomu na něj může dowait čekat.

camera ( ... ) - příkazy kamery#

První hodnota camera volí příkaz. behaved ukazuje každý z nich na časové ose pod Kamera a přehrává ho v pohledu. Časy jsou v milisekundách.

PříkazHodnotyCo dělá (text nápovědy hry)
ENABLE-Přepne hru do režimu kamery
DISABLE-Vyvede hru z režimu kamery
ZOOMčíslo, celé čísloNormální je 80, 10 je přiblíženo, maximum je 120. Druhá hodnota je čas v ms, za který se přiblíží na nové FOV
MOVEvektor, celé čísloPřesun na absolutní počátek vektoru nebo TAG("targetname", ORIGIN) v průběhu daného počtu milisekund
PANvektor, vektor, celé čísloOtočení na absolutní úhel z aktuálního úhlu ve směru dir (bez dir použije nejkratší) v průběhu daného počtu milisekund
ROLLčíslo, celé čísloNáklon o relativní posun aktuálního úhlu v průběhu daného počtu milisekund
TRACKtext, číslo, celé čísloNajet na trať a pohybovat se rychlostí, poslední číslo určuje, zda plynule přejít do výchozí polohy
FOLLOWtext, číslo, celé čísloSledovat entity se shodnou cameraGroup rychlostí angleSpeed, poslední číslo určuje, zda plynule přejít na výchozí úhel
DISTANCEčíslo, celé čísloDržet tuto vzdálenost od cameraGroup (pokud nějaká je), poslední číslo určuje, zda plynule přejít na výchozí úhel
FADEvektor, číslo, vektor, číslo, celé čísloProlnutí z [počáteční červená zelená modrá], [krytí] na [koncová červená zelená modrá], [krytí] (platný rozsah všech polí je 0 až 1) v průběhu [počtu milisekund]
SHAKEčíslo, celé čísloIntenzita (0-16) a doba v milisekundách
PATHtextCesta k souboru ROF

Výrazy: get, tag, random#

Místo pevné hodnoty může pole obsahovat výraz. V editoru je sestaví Pomocník:

  • Načíst - get ( FLOAT, "name" ) čte proměnnou deklarovanou pomocí declare.
  • Tag - tag ( "cam_door", ORIGIN ) vezme polohu (nebo ANGLES) ref_tag v mapě. Tak stojí kamery na značkách.
