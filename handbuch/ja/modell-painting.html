ミッション

モデルタブ: テクスチャペイント

モデルのシェーダーの背後にある画像に直接描きます - 3D のモデル上で (アニメーション再生中も) または平面の画像で - そしてオリジナルのサイズと形式でゲーム用に書き戻します。

ペイント領域#

モデルタブ上部で ペイント 領域を選びます。各サーフェスの画像はゲームが読み込むもの: サーフェスのスキンかシェーダー、なければ同名シェーダースクリプトの最初の map ステージです。左の キャンバス (Blender モード: 画像エディター) はその画像を UV 三角形とともに平面で表示し、右のビューはゲームと同じくシェーダー全体でモデルを表示します。ゲームは各画像を一度だけ読み込むため、その画像を使うすべてのサーフェスのすべてのステージに塗った内容が表示されます (別のシェーダーでも、例: torso と torso_cull)。ビューでのストロークはブラシの下のサーフェスの画像に塗ります - ダブはモデル上の球なので、シームや UV アイランドをまたいでも途切れません。画像でのストロークは 2D で塗ります。マウス位置の円が半径です。各ストロークが 1 回の取り消し単位です (Ctrl+Z、Ctrl+Y)。

ツールとブラシ#

ドロー、ぼかし、スミア、クローン (Ctrl+クリックでソース)、塗りつぶし、マスク、消しゴム はロールアウト ビューポート キャンバス (Blender: テクスチャペイント)、メニュー ペイント、ビューの右クリック、検索にあります。半径、強さ、硬さ (減衰)、間隔でブラシを設定し、ペンでは筆圧でサイズと強さを変えられます。Blender モードでは F と Shift+F で半径と強さをドラッグ、S で色を拾い、X で 2 色を入れ替え、1 でマスクを表示します。ミラー は各ダブをモデルの鏡像側にもう一度塗ります (キャラクターは x 軸)。当たった面から 80 度以上外を向く面は 裏面 がオンでない限り塗られません。

レイヤー、マスク、シーム#

ゲームのオリジナル画像は一番下のレイヤーで、その上のレイヤー (新規レイヤー) に塗る限り変わりません。各レイヤーには不透明度と描画モード (通常、乗算、加算、スクリーン、オーバーレイ) があり、非表示にもできます。下に結合 で下のレイヤーに結合します。マスクはテクセルをすべてのツールから保護し、マスクを表示 で画像に赤く表示します。各ダブの後、UV アイランドのすぐ外側のテクセルは最寄りの塗られたテクセルの色を受けます (にじみ、既定 4 テクセル)。こうして遠くで暗いシームが出ません。UV 領域で UV を変えた場合は、新しい UV に焼き付け で各レイヤーとマスクを古い UV から新しい UV へ移します。

ゲーム用#

ゲーム用にビルド は塗った各画像をゲーム内パス (例: models/players/stormtrooper/...) で出力フォルダーに書き出します - MOD フォルダーか fs_homepath で、ゲームフォルダーには書きません。サイズと形式はオリジナルのまま: .tga は深度と圧縮を保ち、.jpg はオリジナルの量子化テーブルで書かれ、.png は .png のままです。塗っていない画像は書き出されず、ゲームはオリジナルを読み続けます。Movie Duels は .tga より先に .jpg を探すため、ファイルはオリジナルの名前と拡張子を保ちます。レイヤーは JK Studio に残ります。
