ミッション

モデルタブ: アニメーションエリアのパネル

アニメーションエリアの右パネルは、作業の順にグループを表示します: シーケンスとその出力先、リグ、プリセット、既存アニメーションの編集、別のスケルトンからの転送、IK/FK、取り付け、ゲーム用の作成。

グループとタブ#

エリアが指定するタブ (3ds Max 風は モーション、Blender 風は ボーン) には、すべてのグループが縦に並びます: アニメーション、リグを作成、プリセット、既存のアニメーションを編集、転送 (リターゲット)、IK/FK、取り付けとプレビュー、ゲーム用に作成、その後ろに オートフィジックス、ポーズ、ゴースト、モーションパス、カーブとアニメーションツール、ポーズライブラリ、GLA (スケルトンとアニメーション)、animation.cfg、出力先 GLA とスロット。見出しをクリックするとグループが折りたたまれます。他のタブはそれぞれの部分を表示します: 階層 はリグ、IK/FK、取り付け、ユーティリティ はゲーム用の作成、ポーズライブラリ、GLA、animation.cfg、スロット (Blender 風では コンストレイント と データ)。アニメーション は作業中のシーケンス、出力先 GLA、使用中のスロット数を示します。ドープシートとカーブエディターはタイムラインで開きます。

リグを作成: テンプレート#

表にはスケルトン、そのスケール (fScale)、認識されたテンプレートが表示されます。基本ゲームのスケルトン (人型、ランコア、ワンパ、トーントーン、ハウラー、AT-ST、ドロイド、乗り物、船) と他のプログラムのリグ用のテンプレートがあります。下の選択で別のテンプレートまたは 独自スケルトン を設定できます (その場合チェーンは提案され、リグ概要 で変更できます)。テンプレートはアニメーション転送時のターゲットのチェーンも決めます。コントロールリグを作成 は IK ターゲット、ポール、フットロール付きのリグを作り、アニメーションリグ (FK のみ) は回転コントロールだけのリグを作ります。CAT リグと同じく、コントロールリグを作成 はシーケンスのアニメーションを FK から IK に移してリグに載せます: フレームはコントロールのキーになり、手足は IK ターゲットとポールに追従し、動きは同じに見えます (メッセージに最大のずれを表示)。その後、どのフレームでもコントロールを操作します - 手や足のターゲット、ポール (肘、膝) を動かし、足を転がします。リグに載せる は後から読み込んだアニメーションに同じことをします。

コントロールリグを作成 の後の アニメーションリグ (FK のみ): シーケンスで IK になっている手足は、まず各フレームで FK キーにベイクされ (フィギュアのすべてのシーケンス)、その後 IK トラックが削除されます。動きはまったく変わらず、各回転コントロールがボーンを回します。Ctrl+Z で IK トラック、IK ターゲット、ポールが 1 ステップで戻ります。コントロールリグを作成 で IK ターゲットが再び有効になります。既存のアニメーションは、IK/FK で手足を IK に切り替えるか リグに載せる を使うまで FK のままです。

プリセットと既存のアニメーション#

プリセット: デザインの 8 つのカテゴリ (待機、歩き、走り、後退、しゃがみ、ジャンプ、戦闘、ジェスチャー) は常に表示され、その後ろに その他 があります。まだプリセットのないカテゴリには短い案内が出ます。一覧からプリセットを選びます - 出典とライセンスが横に表示されます。歩き と 走り には独自ジェネレーターの 歩き (生成) / 走り (生成) もあります: 選ぶと一覧の下に 速さ と 腕の振り が出て、ジェネレーター でその他 (姿勢、歩幅、腰の振り、上下動、計測) を表示します。フィギュアでプレビュー は読み込みまたは生成してフィギュアのスケルトンに転送し再生します。フィギュアに載せる (リターゲット) は 出力先スロット に置きます。項目の右クリックでも同じ操作ができます。既存のアニメーションを編集: フレームをキーに削減 はシーケンスのフレームをキーに変え (オプションで選択ボーンや範囲に限定)、GLA にベイク は編集したシーケンスを GLA のフレームとして出力先のスロットに書き戻します。転送 (リターゲット): ソースを選ぶかアニメーションをインポートし、表でチェーンを確認してからメインボタンで結果をスロットに置きます。足の滑り は足がどれだけ滑るかを示します。

IK/FK、取り付け、作成#

IK/FK は手足ごとに 1 行です。3ds Max 風では右のボタンが状態を示して切り替えます (手や足を掴む = IK、ボーンを回す = FK)。CAT の手足の IK/FK と同じく現在のフレームから次の切り替えまでで、先にもう一方を合わせる (Match IK and FK) ので、ポーズはジャンプしません。Blender 風では IK から FK へのスライダーと、ジャンプなしでスナップする 2 つのボタンがあります。その下で、選んだ手足のスペース、フットロール、キーを設定します。取り付けとプレビュー はフィギュアに付いているものと再生しているものを示します: 取り付けたモデル、プライマリとセカンダリのシーケンス。ゲーム用に作成 は ルートの移動 (シーケンスで骨盤が床の上を移動する距離) を表示し、animation.cfg 付きの出力先 GLA を作成します。ゲームはこの動きを再生しますが、フィギュアの原点は動かしません: スクリプトで SET_ORIGIN と次のアニメーションを一緒に設定する必要があります。
