はじめに

メニューエディター

ゲームのメニュー(.menu)をテキストと 640x480 のキャンバスで同時に編集します。読み込み・描画・操作はゲームと同じです。

メニューを開く#

モードバーで メニューエディター をクリックします。ゲームから開く は設定したゲームの ui/ メニューをすべて一覧にします(.pk3 から読み込むだけで変更しません)。ファイルを開く かファイルのドロップでディスクから開きます。読み方はパスで決まり、ゲームと同じです:ui/jamp/、ui/jk2mp/、ui/MD_MP/ はマルチプレイのプリプロセッサー(#include、#define、マクロ、menudef.h)、それ以外はシングルプレイと同じです。

エンジンのメッセージ には、ゲームがファイルを読み込むときに出す内容が原文のまま行番号つきで表示されます(例:Unknown item keyword 'foo' Line #21)。クリックするとその行へ移動し、ライブ診断がテキスト内で示します(ライブ診断)。

プロジェクトなしで: メニューが開いていないとき、スタート画面には 新しいプロジェクト と プロジェクトを開く の隣に メニューを開く が表示されます。ゲームから開く、ファイルを開く、メニューセット全体を開く(menus.txt) を選べます。メニューを編集して Ctrl+S を押すと、ゲームフォルダー以外のファイルは同じ場所に書き戻されます。ゲームやそのフォルダーのメニューは、エディターがゲームフォルダーを変更しないため、コピーの保存先を一度だけ尋ねます。バーの上部の同じボタンもそのまま使えます。

キャンバスとページ#

ファイルの menuDef はそれぞれキャンバスの上のタブになります。複数の値を持つ cvar で表示される項目(cvarTest + showCvar、ui_tab のようなページ)は値ごとにタブになります。+ で新しい menuDef を追加します。キャンバスはゲームの仮想 640x480 画面です:元のゲームと同じ 引き伸ばし(オリジナル)、4:3(黒帯あり)、縦横比を確かめるための解像度プリセットがあります。

  • クリックは選択だけで(Shift/Ctrl で追加)、何も動かしません。選択済みの要素をもう一度押してドラッグすると移動します。選択全体が一緒に動き、元に戻す 1 回分です。白いハンドルでサイズ変更します。要素が重なる場所では、押した先はポインターの下で枠と名前が出ている一番手前の要素です。Alt+クリックで重なりを順に選び、Alt+ドラッグで隠れている選択済み要素も動かせます。テキストで変わるのは rect の数値だけで、コメントやインデントはそのままです。
  • 要素の型は変わりません。プロパティ 上部のカードは表示するだけです。別の型が必要なら新しい要素を挿入してください。テキストエディターでは今までどおり何でも書けます。ある行のせいでゲームがメニュー全体を捨てる場合、プレビューは読み進めて要素を元の位置に保ち、キャンバスの上にその行を示します。
  • Ctrl+Z、Ctrl+Y とバーの矢印はメニューエディターのどこでも働き、選択も元に戻します。入力中のフィールドとテキストエディターだけは独自のキーを使います。選択は 1 回分に数えません。
  • ズーム: Ctrl+マウスホイールでポインターを中心にズームします(25~800%)。Ctrl+0 で全体表示、Ctrl+1 で 100%、中ボタンまたは Space+ドラッグで表示を移動します。ズームは表示だけで、元に戻す操作にも数えず、ファイルにも入りません。ルーラー、ハンドル、スナップ、ドラッグはどの段階でも正確です。キャンバスはバーで設定したゲームウィンドウの形になり、指定がなければ 4:3 です。パネルに合わせて伸びることはないので、要素はゲームと同じ高さに見えます。テキストエディターの上では同じキーがそのフォントを変えます。ポインターの下にあるものが対象です。
  • マウスポインター: 押したときの動作を示します。選択した要素のハンドルと縁ではサイズ変更の矢印(縁でも変更できます)、要素の上では移動ポインター、テキストの上ではテキストカーソルです。
  • その場でテキストを書く: キャンバスの要素をダブルクリックして入力します。テキストはゲームのフォント、サイズ、色、折り返しで表示され、カーソル、選択、コピー、貼り付けが使えます。Esc で破棄、Enter または別の場所のクリックで確定します(元に戻す 1 回分)。折り返す要素では Ctrl+Enter で改行します。ゲームのテキスト(@MENUS_...)はそのままで、要素にはプロジェクトのテキストパッケージ内の独自テキストが付き、他の言語は翻訳を保持します。テキストが cvar、ゲーム自身、画像から来ている場合は、ダブルクリックでそう表示します。階層 は行内に、プロパティ は最上部にテキストを表示します。
  • プロパティ の上部には固定カードがあり、アイコン、名前、型と、表示、ロック、前へ、後ろへ、複製、削除のボタンが並びます。その下に既存のイベント、フィールド検索、ファイルのキー(わかりやすい名前にファイルのキーを添えます。検索は両方を見つけます)があります。フィールドは用途ごとのグループにまとまり、閉じたグループは右に要約を表示します。表示するのはゲームがこの種類の要素で読むものだけで、フィールドのない行はファイルに残り ファイル内のその他の項目 に出ます。
  • 数値と色: 数値をクリックすると入力、ラベルをドラッグすると変更できます。値は他をクリックしても残ります。色は 1 行で、色の欄をクリックすると R、G、B、A と最近使った色が開きます。パネル下部の行は、ポインターの下のフィールドの働きをすぐに示します。小さな矢印はゲームの既定値と異なる値を示し、クリックするとその行をファイルから取り除きます。
  • 配置は保たれます: 配置ボタンが書くのは textalign、textalignx、textaligny だけです。これらの数値が規則に合っている間は、中央や右揃えの文字は要素のサイズが変わっても位置を保ちます(縦方向も)。自分で数値を入れると、その要素では止まります。
  • 何も選択していないとき、パネルはメニュー自体を表示します。名前、全画面 か オーバーレイ、背景、イベントでは開く・閉じる・Esc・Enter のときの動作です。2 つ以上の要素では すべて変更(文字サイズと色。混在する値は示されます)と 配置 を表示し、どちらも元に戻す操作は 1 回です。コンポーネント、プレビューの Cvar、エンジンのメッセージ はパネル下部の小さなボタンです。
  • 空のメニュー: 全画面ではゲームはその下に何も描きません。シングルプレイでは空のメニューは黒です(backcolor がないと background の通常の画像も見えません)。マルチプレイでは background か要素が覆うまで灰色の標準ボックスを表示し、診断がそれを知らせます。全画面でない場合はメニューを通して背後が見えます。キャンバスは市松模様で示し、オフにでき、ファイルには入りません。
  • 端にスナップ はほかの項目・画面・ガイド(ルーラーから引き出す)の端と中央にスナップし、グリッドにスナップ はグリッドにスナップします。ドラッグ中に Alt でスナップを切り、Shift で方向を固定します。矢印キーで 1、Shift 併用で 10 移動します。新規・貼り付け・複製した要素が同じ大きさの要素にぴったり重なることはありません。右下へ 20 ポイントずれます。Alt を押しながらドラッグすると、放した位置にそのまま置きます。枠がぴったり重なっているときは、ヒントは 1 回だけ表示されます。
  • 左パネルは部品をタイルで表示します。表示 は見るだけのもの、プレイヤー入力 はプレイヤーが操作するもの、完成部品 は設定済みの部品(ツールチップに内容と要素数)、マイテンプレート は自分のものです。タイルをキャンバスへドラッグすると、枠が置き場所を示し、移動と同じようにスナップします。ダブルクリックは中央の、既存のものの隣に置きます。クリックだけでは何も起きません。ボタン には見える塗りが付いています。選択をテンプレートとして保存 は選択があるときだけ使え、そのあとで名前を尋ねます。テンプレートは要素の小さな絵を表示し、名前の変更と削除ができ、削除したものは元に戻せます。
  • 画像と動画: 挿入は枠を置くだけで、ファイルダイアログは開きません。枠は選択されたままで、キャンバスに次の操作を示します。この案内はプレビューだけのもので、ファイルには入りません。枠のダブルクリックか Properties の 選択 で選択画面が開きます。ゲームとプロジェクトの画像やシェーダー(検索と小さな絵つき)、またはゲームの動画と ファイルから です。ファイルの動画は変換画面を通ります。ゲームの動画はコピーされず、シェーダーだけがパッケージに入ります。画面全体、最背面 は枠を画面全体に広げ最背面に置きます。挿入も選択もそれぞれ元に戻す操作 1 回で、パッケージも戻ります。メニューの動画はゲームでは無音です。未選択ならゲームは灰色のボックスを表示し、検査が指摘し、書き出しが警告します。
  • カードの 前面へ/背面へ は描画順を変えます(ゲームはファイルの順に描きます)。鍵は項目の移動を防ぎ、目は visible を書きます。

選択、右クリック、メニューの管理#

  • 複数を選ぶ: 空いている場所からドラッグして枠を描くと、触れたものすべてが選ばれます。Ctrl または Shift で追加、Ctrl+A ですべて選択します。ロック中と非表示の要素は含まれません。
  • 要素または階層の行を右クリック: 切り取り、コピー、貼り付け、複製、削除、最前面へ、最背面へ、ロック、プレビューで隠す、自分のテンプレートとして保存。キャンバスでは、ポインターの下にあるものも一覧にします。
  • 背景はクリックを通します: 画面全体を覆う装飾を誤って動かすことはありません。変更するには、階層、右クリックメニュー、または Alt+クリックで選びます。
  • メニューの管理: キャンバスの上のタブを右クリックすると、そのメニューの名前変更、複製、削除、移動ができます。名前変更はこのファイルの open と close も変更します。どれも元に戻す 1 回分です。
  • スペースが少ないとき: キャンバスの上の 2 つの矢印で左右のパネルを閉じられます。小さなウィンドウでは左パネルが自動で閉じ、表示スイッチは 表示 ボタンの中に移ります。

条件: 条件 で、設定が要素を表示、非表示、使用可、使用不可のどれにするかを選びます。複数選択 要素の 選択肢 はテキストと値のリストです。リストとゲームが描く要素には ゲームが内容を入れる グループがあります。ゲームが読めないものはメッセージとともに拒否され、メニューはそのままです。

操作と Cvar#

操作 ではゲームと同じようにメニューが動きます:マウスを重ねるとフォーカス(mouseEnter、onFocus)、クリックで項目の action を実行し、はい/いいえ・複数選択・スライダーは cvar を変え、open、close、show、hide、setfocus、setcvar、setitemtext、transition などは ui_shared と同じように働きます。ゲームが必要なもの(サウンド、exec、uiScript)は スクリプトログ に表示されます。

プレビューの Cvar にはメニューが読む・設定するすべての cvar が、表示を制御するものを先頭に、出てくる値とともに並びます。変えるとほかの状態を確認できます。プレビューの中だけのもので、ゲームの設定には一切触れません。

コードエディター#

Ctrl + wheel / Ctrl + 0テキストエディターの文字サイズ(50~300%)。ポインターをテキストの上に置きます。Ctrl+0 で既定に戻ります。表示だけで、元に戻す操作に数えず、ファイルにも入りません。サイズは記憶されます
Alt + Z長い行の折り返しを切り替えます(VS Code と同じ。初期設定はオン、ファイルは変わりません)。折り返しなしでは Shift+マウスホイールまたは下のスクロールバーで横に動きます
Ctrl + F / Ctrl + H検索と置換(スクリプト領域と同じ。正規表現、大文字小文字、単語単位、開いているすべてのメニュー)。すべて置換は 1 回の元に戻す操作で件数を表示します。Ctrl+H は置換欄にカーソルを置きます。一致箇所はミニマップに表示
Ctrl + D / Ctrl + Shift + L / Alt + Click次の一致/すべての一致/カーソル追加(マルチカーソル)
Ctrl + Space補完:キーワード、cvar、項目名、シェーダーのパス、@MENUS 文字列
F12 / Ctrl + Clickカーソル位置の名前の menuDef/itemDef へ移動
Ctrl + F2 / F2 / Shift + F2スクリプトエディターと同じブックマーク(余白のクリックでも)
Ctrl + / , Tab / Shift + Tab行のコメント化、インデント/解除

余白はスクリプトエディターと同じです:オレンジ = 保存後に変更、緑 = 変更して保存済み、青 = 開いたときの状態に戻った行。menuDef、itemDef、スクリプトのブロックは行番号の横の +/- で折りたためます。キャンバスの項目をクリックするとその itemDef へ移動し、itemDef 内のカーソルでその項目が選ばれます。

保存とエクスポート#

保存 はエディターのテキストをそのまま書き込みます。ゲームから開いたファイルは別の場所に保存します。.pk3 をエクスポート はメニューをゲーム内のパスで、画像とともに .pk3 にまとめます。どちらもゲームのフォルダーには書き込みません。

ゲームと同じように描画します:フォントは .fontdat、文字の位置は RE_Font_DrawString、項目の種類は ui_shared と同じです。実行中のゲームが必要なもの(番号つきの ownerdraw 項目、リストのフィーダー、3D モデル、ムービー)はプレースホルダーで示します。
前へマップエディター:ゲーム内テストとその他のツール次へメニューエディター: プレビュー、検査、パッケージ
