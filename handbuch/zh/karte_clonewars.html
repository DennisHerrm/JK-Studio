地图与场景

地图编辑器:测试人物、比例与 clip 工具

来自一个 Clone Wars 模组需求的工具:原始尺寸的玩家人物、以正确比例和坐标轴导入模型、在地图中加注缩放房间、为楼梯和墙提供平滑碰撞。所有功能默认关闭,或只在调用时才起作用。

测试人物#

视图 > 测试人物 > 显示测试人物(F7,或工具栏末尾的按钮)在 2D 视图和相机中以原始尺寸显示玩家:引擎移动的盒子(单人和 Movie Duels 为 32 x 32 x 64,多人模式宽 30;原点在髋部高度,脚在其下 24;蹲下时顶部在 16 而不是 40——OpenJK g_client.cpp 和 bg_public.h)、脚上方 18 的 STEPSIZE 标记、另一种高度,以及优化器中门和走廊最小尺寸的框。在相机中,游戏的玩家模型站在其中,姿势与玩家静止时游戏中的姿势相同(蹲下时为蹲下动画保持的最后一帧)。

Shift+F7 把人物放到鼠标指针下:在 2D 视图中放到视图的两条轴上(深度不变),在相机中双脚落在表面上。在视图中右键单击会提供 测试人物放到这里,在工具栏按钮上右键单击会显示整个菜单。默认关闭;所做选择会被记住。

按比例和坐标轴导入#

文件 > 导入几何体 对话框中有 模板:默认(与以前相同) 完全按以前的方式读取文件(默认),Battlefield 3 / Y 向上 把 Y 向上转换为 Z 向上,即 (x, -z, y),Battlefront 2 / Z 向上 保持坐标轴不变,Source / GMod(x 0.889) 保持坐标轴并按 64 / 72 缩放(Source SDK 2013 中玩家高 72 单位,这里是 64),自定义坐标轴 允许为 X、Y、Z 选择文件的轴。翻转环绕方向/法线 用于三角形环绕方向相反的模型(Empire at War)。对话框显示以单位和测试人物计的尺寸,高度 = 测试人物 把角色模型缩放到 64,正视图显示模型和旁边的测试人物。模板会被记住;把文件拖到视图上时也会使用它。

Clip 工具与图层 Collision#

修改 > Clone Wars 工具(选中内容时也在视图右键菜单顶部)作用于所选内容,每次一个撤销步骤:

  • 楼梯转为 clip 坡道:选择由画刷构成的楼梯或一个 misc_model。一个由 textures/system/clip 构成的平滑坡道(玩家和 NPC;射击仍会打到台阶)从楼梯底部穿过各级台阶的前缘到最上面的踏面。可见台阶按 q3map2 的理解失去碰撞:一个被遮挡的面(caulk,否则为底面)变为非实体的 system/nodraw,而只要有一面非实体,整个画刷就可穿过;模型失去其 clip 生成标志;所选内容中的纯碰撞画刷被删除。用 q3map2 编译后,玩家会平滑地走上去而不是一级级跳;优化器的视觉与碰撞检查在那里不再报告问题。比可行走更陡(MIN_WALK_NORMAL 0.7)的坡道会得到警告。
  • 平滑 clip 墙(平面) / 平滑 clip 墙(凸包):选择一面不规则的墙(画刷、面片或 misc_model)。平面方式沿墙放置一个 clip 长方体,其前面位于最突出的点,在相机一侧;凸包方式使用所选内容的凸包。
  • 缩放房间:以所选内容底部中心为基准按系数缩放所选内容(一个房间);点实体随之移动,模型保持大小。该点处的 info_notnull 获得 cw_scale(和 cw_room),.map 中得到一行注释 "// cw_scale ..."——只是数据,游戏和 q3map2 都会忽略。缩放并另存为部分 随后把房间连同标记另存为单独的部分(文件 > 保存所选)。
  • 图层 Collision:这些工具的 clip 画刷——以及检查配置为 Clone Wars 流程时“模型 + clip”的 clip 画刷——放入名为 Collision 的单独图层。只有使用其中之一时它才会出现;同一菜单中的 显示图层 Collision(或图层浏览器)可以显示和隐藏它。
