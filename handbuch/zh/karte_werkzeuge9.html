地图编辑器:在游戏中测试及更多工具

一键用当前地图启动游戏,并把来自 Blender 和其他游戏的模型转换为画刷。

在游戏中测试#

编译 > 在游戏中测试 列出首选项中的引擎以及在引擎文件夹中找到的所有游戏程序:Jedi Academy SP/MP、OpenJK、Movie Duels;对于 Jedi Outcast 地图则是 Jedi Outcast SP/MP 和 OpenJO。单击即可用当前地图(+devmap)启动所选程序。所做的选择会被记住。

  • 使用哪个 .bsp:如果当前地图的快速烘焙是最新的(快速烘焙)就用它;否则使用比已保存且未更改的地图更新的 .bsp;再否则程序先用 Build 菜单中第一个 [Test] 条目编译,编译完成后启动游戏。
  • 放到哪里:.bsp 会被打包为 zzz_jkstudio_test.pk3,放在程序设置旁边的 spieltest 文件夹中——绝不会放入游戏文件夹。游戏通过启动参数得知该文件夹:fs_cdpath(该系列的所有引擎;你的游戏设置保持不变),或者当游戏已有同名地图时使用 fs_homepath(Jedi Academy MP、Jedi Outcast MP、OpenJK、Movie Duels),因为该文件夹优先。程序支持哪个参数是从其 .exe 中读取的。
  • 只有两者都不可用时(例如 Jedi Academy SP 且地图名称游戏中已存在),程序才会在把存档写入游戏前询问:写入模组文件夹 jkstudio_test(以 +set fs_game jkstudio_test 启动),或写入当前模组的文件夹。之后可以删除该文件。
  • 控制台会显示所选方式和完整的命令行。带空格的地图名称无法用 devmap 加载;请用不含空格的名称保存地图。
NetRadiant-Custom 中没有。NetRadiant-Custom 自带的 编译后运行游戏(首选项,Build 页)保持不变:它在每次编译后从游戏文件夹启动引擎。

几何体转画刷#

文件 > 将几何体导入为画刷 读取模型(.obj、.fbx、.glb 或 .gltf,例如来自 Blender)并把它转换为画刷。窗口会列出文件中的部件;为每个部件选择 自动、画刷 或 模型 + 碰撞——预览 列会立即显示会生成多少个画刷以及它们是否为 detail。插入 以一步撤销插入全部内容并选中;之后会打开优化器。

  • 封闭部件会被分解为凸画刷(对模型的面构建 BSP,与 q3map2 的做法相同)。同一平面上的面合并为一个画刷面。位于模型表面的画刷面使用其材质作为着色器(着色器前缀 + 材质名),并以其 UV 作为纹理对齐;模型内部看不到的面使用 caulk。
  • 开放部件(单个面、装饰)会在每个平面后方生成薄画刷;小部件和开放部件设为 detail,这样不会把地图切成 BSP 叶。
  • 模型 + 碰撞 将部件保留为模型:它以 .obj 写入程序的导入文件夹(在设置旁边,绝不写入游戏),由 misc_model 引用,并用同一分解得到的 clip 画刷使其成为实体。编辑器和 q3map2(-fs_pakpath)都会搜索该文件夹。自动 对最多 256 个画刷的封闭部件使用画刷,否则使用模型 + 碰撞。
  • 缩放 和 Y 轴向上(Blender、glTF)转为 Z 轴向上:Blender 和 glTF 以 Y 轴为上,游戏以 Z 轴为上;不缩放时一个 Blender 米等于一个单位。其他 id Tech 3 游戏(Quake III、Elite Force、Return to Castle Wolfenstein、Enemy Territory、Warsow)的 .bsp 会像 打开 .bsp 一样用该游戏的读取器打开。

把模型拖入地图#

把 .obj、.fbx、.glb 或 .gltf 文件从资源管理器拖到地图编辑器上。程序会把它转换为带自己着色器的 MD3,并复制纹理(嵌入在文件中或位于文件旁);所有内容都放入设置旁的导入文件夹,绝不写入游戏。一个 misc_model 会出现在二维视图中的鼠标指针下(否则在摄像机前方)并被选中;撤销一次即可移除。超过 511 单位的模型会在 MD3 中缩小并获得 modelscale。

在游戏中测试 会把导入文件夹打包进测试存档,使游戏能找到模型、着色器和纹理。发布时,请把导入文件夹中的 models/import 文件夹和 scripts 复制到你的模组或 pk3 中。

检查跳跃与空间#

视图 > 检查跳跃与空间 > 检查(所选内容或摄像机周围) 使用游戏的移动方式检查所选内容(否则为摄像机周围 512 单位):玩家可以站立的位置(绿色十字)或只能蹲下的位置(黄色),以及从哪些边缘助跑跳跃能落到另一层地面——蓝色为普通跳跃,紫色为只有所选等级的原力跳跃才能到达。它在后台运行;清除 会清除显示。

  • 移动是游戏代码的移植:奔跑速度 250、重力 800、跳跃 225、玩家盒 32 x 32 x 64(蹲下 40)、台阶最高 18 单位、地面坡度最高 45 度。原力跳跃与游戏一致:按住跳跃键时最高上升 96、192 或 384 单位(等级 1 到 3);提前松开则跳得更低。Jedi Outcast 和 Movie Duels 的计算方式相同。
  • 所选的原力跳跃等级也适用于 在编辑器中游玩(F6):按住空格键可以跳得更高。

NPC 路径#

视图 > NPC 路径 > 显示路点网络 显示游戏加载地图时由路点构建的网络——连接为青色,跳跃连接为橙色。游戏只有在超过三个路点时才构建网络;控制台会提示。试走(从第一个到最后一个选中的实体):选择两个实体(例如两个路点,或一个 info_player_start 和一个路点)——一个 NPC 使用游戏的寻路和移动从第一个走到最后一个;路径为黄色,一个方框实时沿路径移动。控制台会显示几秒后到达,或在哪里卡住。奔跑 在奔跑和行走之间切换。
