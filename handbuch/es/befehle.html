Referencia

Todos los comandos

Lo que hace cada comando de la lista de eventos, cada comando de cámara, cada macro y cada campo SET_, con el valor que espera.

Los comandos se insertan desde la lista Eventos (doble clic, arrastrar o Insert) y se cambian en el Editor de eventos (doble clic en la línea). Pasa el ratón por encima de un comando de la lista para leer el texto de ayuda que escribieron para él los diseñadores del juego. Cómo combinarlos: Escribir scripts.

Los comandos de la lista de eventos#

Cada comando tiene su propia página con imágenes del editor y de las tres vistas: Comandos uno a uno.

ComandoQué haceEjemplo
flushBorra cada comando que aún espera para esta entidad: lo que hace un bloque affect con FLUSH al empezar.flush ( )
if / elseEjecuta el bloque solo si se cumple la comparación (=, <, >, ! para *distinto*). else debe seguir justo después de un if.if ( $get( FLOAT, "count")$, $>$, $2$ )
loopRepite su bloque; el número dice cuántas veces, -1 significa para siempre.loop ( 3 )
affectEnvía los comandos de su bloque a una entidad (una figura, una nave, una puerta) por su nombre. FLUSH sustituye lo que estaba haciendo la entidad, INSERT lo añade. El script en sí no espera al bloque.affect ( "kyle", FLUSH )
runInicia otro script en la entidad que ejecuta este.run ( "taspir_tut/kyle_spawn" )
waitHace una pausa de tantos milisegundos o, con un nombre, hasta que termina esa tarea.wait ( 2000 )
waitsignalHace una pausa hasta que algún otro script llama a signal con el mismo nombre. Solo un script puede esperar una señal dada.waitsignal ( "door_open" )
signalDespierta al script que espera este nombre.signal ( "door_open" )
soundReproduce un sonido en un canal de la entidad: CHAN_VOICE para el diálogo, así se mueve la boca.sound ( CHAN_VOICE, "sound/chars/kyle/..." )
moveMueve una entidad (una puerta, una plataforma, una nave) a una posición (y, si se indica, a ángulos nuevos) en tantos milisegundos. La ventana de animación los escribe por ti (Una puerta que se abre).move ( < 0 0 128 >, < 0 0 0 >, 2000 )
rotateGira una entidad a unos ángulos (cabeceo, guiñada, alabeo) en tantos milisegundos.rotate ( < 0 90 0 >, 1000 )
useUsa una entidad por su nombre, como si el jugador la pulsara: abre una puerta, dispara un trigger.use ( "door1" )
killMata a la entidad con este nombre.kill ( "stormie1" )
removeQuita del juego la entidad con este nombre.remove ( "stormie1" )
printMuestra un texto en el centro de la pantalla.print ( "Hello" )
remUn comentario: no hace nada en el juego. Comentar convierte cualquier línea en uno.rem ( "camera starts here" )
declare / freeDeclara una variable (FLOAT, STRING, VECTOR; como máximo 16 por mapa); free devuelve el nombre.declare ( FLOAT, "count" )
setCambia un valor: un campo de entidad (SET_NAVGOAL, SET_ANIM_BOTH, ...; mira la lista completa abajo) o una variable declarada.set ( SET_WALKING, "true" )
cameraControla la cámara de la cinemática; el primer valor elige lo que hace: mira la sección siguiente.camera ( ENABLE )
taskDeclara un grupo de comandos con nombre; todavía no se ejecuta.task ( "walk" )
doInicia una tarea y sigue enseguida.do ( "walk" )
dowaitInicia una tarea y espera a que termine; para una marcha: hasta que la figura haya llegado.dowait ( "walk" )
playReproduce un archivo ROFF en la entidad del bloque affect actual: un movimiento grabado.play ( PLAY_ROFF, "taspir_tut/roffs/ravensClaw" )
Un comando marcado con * en su texto de ayuda (por ejemplo SET_NAVGOAL) solo termina su tarea cuando la acción ha concluido: eso es lo que deja que dowait lo espere.

camera ( ... ): los comandos de cámara#

The first value of camera chooses the command. behaved shows every one of them in the timeline (in the Detail view in its own row) and plays it in the view. Times are in milliseconds.

ComandoValoresQué hace (texto de ayuda del juego)
ENABLE-Pone el juego en modo cámara
DISABLE-Saca el juego del modo cámara
ZOOMnúmero, número enteroLo normal es 80, 10 es zoom cercano, el máximo es 120. El segundo valor es el tiempo en ms para llegar al nuevo FOV
MOVEvector, número enteroMoverse a un origen vectorial absoluto o TAG("targetname", ORIGIN) en un número de milisegundos
PANvector, vector, número enteroGirar a un ángulo absoluto desde el ángulo actual en la dirección indicada (sin dirección usa la más corta) en un número de milisegundos
ROLLnúmero, número enteroAlabear a desplazamientos de ángulo relativos al ángulo actual en un número de milisegundos
TRACKtexto, número, número enteroPonerse en el recorrido y moverse a esa velocidad; el último número indica si interpolar o no hasta la posición inicial
FOLLOWtexto, número, número enteroSeguir a las entidades con el cameraGroup coincidente a angleSpeed; el último número indica si interpolar o no hasta el ángulo inicial
DISTANCEnúmero, número enteroMantener esta distancia del cameraGroup (si hay); el último número indica si interpolar o no hasta el ángulo inicial
FADEvector, número, vector, número, número enteroFundido de [Rojo Verde Azul iniciales], [Opacidad] a [Rojo Verde Azul finales], [Opacidad] (todos los campos van de 0 a 1) en [número de milisegundos]
SHAKEnúmero, número enteroIntensidad (0-16) y duración, en milisegundos
PATHtextoRuta al archivo ROF

Expresiones: get, tag, random#

En vez de un valor fijo, un campo puede contener una expresión. En el editor, Ayuda las construye:

  • Obtener: get ( FLOAT, "nombre" ) lee una variable declarada con declare.
  • Etiqueta: tag ( "cam_puerta", ORIGIN ) toma la posición (o ANGLES) de un ref_tag del mapa. Así se colocan las cámaras sobre marcas.
  • Aleat: random ( 1000, 3000 ) un número aleatorio entre dos valores, por ejemplo para una espera.
