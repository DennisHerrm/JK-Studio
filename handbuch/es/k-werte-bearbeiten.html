Tutoriales: scripts

Cambiar los valores de un comando

El editor de eventos: listas, números, campos de archivo, nombres del mapa, y expresiones como get, tag y random.

Vista:

Pasos#

  1. 1

    Abre el editor. Haz doble clic en una línea del árbol o selecciónala y pulsa Intro. El texto de ayuda del comando está arriba; debajo, cada valor tiene su propio campo.

  2. 2

    Campos para valores. Los números, vectores y texto se escriben en sus campos. Un vector como una posición tiene tres números separados por espacios.

  3. 3

    Campos con opciones fijas. Los campos como SET_TYPES o true / false son listas en las que también puedes escribir: empieza a escribir para filtrar la lista. Se permite un valor que no esté en la lista (los mods traen los suyos), pero se marca como desconocido: revisa si hay una errata.

  4. 4

    Archivos. Los campos de archivo tienen para elegir un archivo del juego y Ejecutar para reproducir un sonido o abrir un script. Con un mapa cargado, una flecha junto a los campos de nombre elige un nombre del mapa.

  5. 5

    Expresiones. Algunos campos tienen Ayuda: te construye una expresión; Obtener lee una variable (get), Etiqueta el lugar o los ángulos de un ref_tag (tag), Aleat un número aleatorio (random).

  6. 6

    Texto libre. Otros campos tienen ¡Expresión!: convierte el campo en texto libre, para cualquier cosa que las listas no ofrezcan. Revertir vuelve a un valor simple.

  7. 7

    Listo. Aceptar (Intro) escribe los valores en el script, Cancelar (Esc) lo deja todo como estaba. Bajo cada campo ves el valor que tenía antes (..... antes).

  1. 1

    Abre el editor. En Grafo, haz doble clic en una línea de Comandos de este script (o selecciónala y elige Editar... en su menú de clic derecho). El Editor de eventos es el mismo en todas las vistas.

  2. 2

    Campos para valores. Los números, vectores y texto se escriben en sus campos. Un vector como una posición tiene tres números separados por espacios.

  3. 3

    Campos con opciones fijas. Los campos como SET_TYPES o true / false son listas en las que también puedes escribir. Se permite un valor que no esté en la lista, pero se marca como desconocido.

  4. 4

    Expresiones y texto libre. Ayuda construye get, tag y random; ¡Expresión! convierte un campo en texto libre.

  5. 5

    Listo. Aceptar escribe los valores, Cancelar lo deja todo como estaba. La línea de la derecha muestra enseguida los valores nuevos.

  1. 1

    Abre el editor. En Pistas, haz doble clic en un bloque o en una línea de la lista de comandos. El Editor de eventos es el mismo en todas las vistas.

  2. 2

    Cambia un tiempo arrastrando. Arrastra el borde derecho de un bloque: un wait, un movimiento de cámara o una marcha se alarga o se acorta. El valor del script cambia con él.

  3. 3

    Campos para valores. Los números, vectores y texto se escriben en sus campos.

  4. 4

    Campos con opciones fijas. Listas en las que también puedes escribir; se permite un valor desconocido, pero se marca.

  5. 5

    Listo. Aceptar escribe los valores; el bloque se mueve o cambia de longitud enseguida.
