Installieren und aktualisieren

Ein Download: JK-Studio-Starter.exe holt JK Studio, prüft es, hält es aktuell und startet es. Updates laden nur, was sich seit deiner Version geändert hat.

Der Starter#

Lade JK-Studio-Starter.exe von der Release-Seite (unter Assets; die Adresse github.com/DennisHerrm/JK-Studio/releases/latest/download/JK-Studio-Starter.exe liefert immer den neuesten). Leg ihn in einen eigenen Ordner, zum Beispiel Dokumente, und starte ihn. Beim ersten Start lädt er das ganze Programm in einen Ordner JK-Studio neben sich, prüft den Download und startet JK Studio. Jeder weitere Start sieht zuerst nach einer neueren Version, lädt sie, wenn es eine gibt, und startet dann das Programm.

  • Ordner: JK Studio liegt neben dem Starter in JK-Studio, als hättest du das Zip dort ausgepackt. Liegt der Starter in einem JK-Studio-Ordner (neben jkstudio.exe), aktualisiert er diesen Ordner. JK-Studio\jkstudio.exe kannst du jederzeit direkt starten.
  • Rechte: der Starter fragt nie nach Administratorrechten. Kann er neben sich nicht schreiben (etwa in Programme), sagt er das - leg ihn dann in einen eigenen Ordner.
  • Abbrechen: Abbrechen (beim ersten Start) oder Ohne Update starten (wenn eine Version installiert ist) hält das Laden an; nichts wird geändert.
  • Ohne Verbindung: startet der Starter die installierte Version. Ist noch nichts installiert, sagt er das und bietet Noch einmal an.
  • Geprüft: jeder Download wird gegen SHA256SUMS.txt des Releases (und deren Signatur) geprüft, bevor sich etwas ändert; ein Update kommt ganz oder gar nicht.

Updates: nur, was sich geändert hat#

Ein Update lädt nicht mehr das ganze Programm. Für jede der letzten Versionen trägt ein Release ein Delta mit nur den Inhalten, die diese Version noch nicht hat - große Teile des Handbuchs und der Daten bleiben von einer Version zur nächsten gleich. Der Starter und die Update-Leiste von JK Studio (siehe Updates und Änderungsliste) nehmen das Delta, das zur installierten Version passt; gibt es keins oder wurde eine Datei im Ordner von Hand geändert, laden sie stattdessen das ganze Paket. Jede Datei wird gegen die unterschriebene Liste der neuen Version (…-manifest.txt) geprüft.

Von rc611 auf rc612 zum Beispiel blieben 4183 von 5980 Dateien gleich; das Delta hat 131 MB statt der 449 MB des ganzen Pakets. Ältere Versionen als die letzten und JK Studio bis rc612 nehmen wie bisher das ganze Paket.

Ohne den Starter#

Das ganze Programm steht auch als JK-Studio-…-windows-x64.zip auf der Release-Seite: auspacken, den Ordner JK-Studio öffnen und jkstudio.exe starten (neben ihrem Ordner data lassen). Es aktualisiert sich genauso.

Windows SmartScreen warnt beim ersten Mal womöglich, weil der Starter nicht codesigniert ist: Weitere Informationen → Trotzdem ausführen. SHA256SUMS.txt nennt jede Datei des Releases; einen Download prüft certutil -hashfile JK-Studio-Starter.exe SHA256.
