Install and update

One download: JK-Studio-Starter.exe fetches JK Studio, checks it, keeps it up to date and starts it. Updates load only what has changed since your version.

The starter#

Download JK-Studio-Starter.exe from the releases page (under Assets; the address github.com/DennisHerrm/JK-Studio/releases/latest/download/JK-Studio-Starter.exe always gives the newest one). Put it into a folder of your own, for example Documents, and start it. On the first start it downloads the complete program into a folder JK-Studio next to it, checks the download and starts JK Studio. Each later start first looks for a newer version, loads it if there is one and then starts the program.

  • Folder: JK Studio lives next to the starter in JK-Studio, as if you had unpacked the zip there. If the starter lies inside a JK Studio folder (next to jkstudio.exe), it updates that folder. You can always start JK-Studio\jkstudio.exe directly.
  • Rights: the starter never asks for administrator rights. If it cannot write next to itself (for example in Program Files), it says so - move it into a folder of your own.
  • Cancel: Cancel (on the first start) or Start without updating (when a version is installed) stops the download; nothing is changed.
  • Offline: without a connection the starter starts the installed version. If nothing is installed yet, it says so and offers Try again.
  • Checked: every download is checked against SHA256SUMS.txt of the release (and its signature) before anything changes; an update goes in as a whole or not at all.

Updates: only what has changed#

An update no longer downloads the whole program. For each of the last versions a release carries a delta with only the content that version does not have yet - large parts of the guide and the data stay the same from one version to the next. The starter and the update bar of JK Studio (see Updates and changelog) take the delta that fits the installed version; if there is none, or if a file in the folder was changed by hand, they load the complete package instead. Every file is checked against the signed list of the new version (…-manifest.txt).

From rc611 to rc612, for example, 4,183 of 5,980 files stayed the same; the delta has 131 MB instead of the 449 MB of the complete package. Versions older than the last few, and JK Studio up to rc612, take the complete package as before.

Without the starter#

The complete program is also on the releases page as JK-Studio-…-windows-x64.zip: unpack it, open the JK-Studio folder and start jkstudio.exe (keep it next to its data folder). It updates itself in the same way.

Windows SmartScreen may warn the first time, because the starter is not code-signed: More info → Run anyway. SHA256SUMS.txt lists every file of the release; a download can be checked with certutil -hashfile JK-Studio-Starter.exe SHA256.
